# What will break / 已知限制

1. **Screen-share invisibility / 屏幕共享不可见：不保证。** Peek calls `setContentProtection(true)` and prints a startup warning. Electron uses `NSWindowSharingNone` on macOS and `WDA_EXCLUDEFROMCAPTURE` on Windows. Modern macOS apps using ScreenCaptureKit can still capture the window. Projectors, mirrored displays, capture cards, cameras and other capture paths may show it. Test the audience-side output with the actual setup; a successful local screenshot test proves little. [Electron documentation](https://www.electronjs.org/docs/latest/api/browser-window#winsetcontentprotectionenable)

2. **Audio device routing / 音频路由：不会自动接通。** Peek records one selected input. A microphone is not the computer’s playback audio. BlackHole needs explicit output routing; a multi-output device does not mix your microphone into playback. Aggregate-device channels may also need a mixer before Peek can hear both sides. Device IDs can change after hardware, permission or session changes. The real meeting or presentation audio path has not been verified. [BlackHole routing guide](https://github.com/ExistentialAudio/BlackHole/wiki/Getting-Started%3A-Creating-a-Multi-Output-Device)

3. **Live services / 真实 API 尚未验证。** Automated tests and mocked streams do not prove a real key’s access, billing balance, model availability, latency, regional reachability or quotas. No successful paid OpenAI or Qwen production request is claimed. The key window’s verification uses a model-list request to check connection/authentication; it does not prove available credit or permission to call chat, vision, or transcription. Restricted keys and some compatible providers may deny this check despite supporting other requests; “Save only” is available. A Qwen chat endpoint does not provide Whisper compatibility automatically. Peek has no internet search tool.

4. **Library relevance / 资料检索会漏。** This is an in-memory lexical index with English terms and Chinese bigrams, not embeddings or a semantic database. Synonyms, translations, pronouns and indirect questions can miss relevant passages. Focus reserves context from one article and still permits wider support; a section filter excludes other sections. No match does not mean the vault contains no answer. Add bilingual aliases and verify the displayed sources. A synthetic 100 × 10,000-word test checks capacity, not real literature-answer accuracy.

5. **Document formats and size / 格式与大小有限。** Only Markdown and plain text are indexed. PDF, OCR, attachments, linked web pages and plugin-generated Obsidian content are not imported. The index skips hidden folders and symlinks and caps files at 10 MB, the corpus at 100 MB, documents at 2,000, and passages at 60,000. Oversize or unreadable files produce warnings. Edits require reload; line references can become stale if an article changes afterward.

6. **Screenshot context / 当前屏幕的定义有限。** “Active display” means the display containing the pointer at request time, not guaranteed foreground-window ownership. PNGs are resized to at most 1,600 pixels wide; small slide text can become unreadable. Screen permissions, protected content and multiple-display behavior can prevent capture. Peek cannot infer off-screen pages or the full content of an article from its screenshot alone.

7. **Speech delay and gaps / 转写有延迟和缺口。** Audio is recorded in independently decodable five-second WebM clips. Restarting MediaRecorder can introduce small gaps or split words. Pressing Answer flushes the current clip and waits up to seven seconds for its transcription. If it is not ready, Peek shows a retry notice and does not call the answer model for that press. A successful transcription response still does not guarantee every spoken word was recognized. A bounded queue drops old audio when the service falls behind; repeated failures pause capture. Silence can produce inaccurate text, and recognition is not guaranteed for names, accents or mixed languages. Audio paused in the UI clears the rolling buffer; hiding the window does not pause it.

8. **Answer and thread limits / 回答与对话有限。** The prompt asks for answers under 60 words, but this is not a hard output validator; Chinese word counts are ambiguous. The model can invent facts or citations. Displayed sources are selected evidence, not proof that every claim is supported. The primary shortcut continues the current thread automatically; use “New topic” to clear prior Q&A when changing subjects. Thread state is bounded, held in memory, and lost on exit. There is no typed-question fallback in the conversation UI, so poor audio or transcription can leave the spoken question unclear. This is a prompt assistant, not a complete literature-review engine.

9. **Pinned dependencies / 指定版本已过维护期。** Electron 30 is retained because the requested stack specifies it; it reached end of life on **14 October 2024** and does not receive current security fixes. `npm audit` reports known Electron/download/build-tool advisories; this repository is not a security-clean production release. OpenAI has announced **26 February 2027** shutdown for `whisper-1`. Both will require explicit upgrades and regression testing. [Electron release schedule](https://releases.electronjs.org/schedule), [OpenAI deprecations](https://developers.openai.com/api/docs/deprecations)

10. **Packaging and permissions / 安装与权限仍需实机验证。** macOS builds are unsigned and unnotarized. Gatekeeper may block launch; development Electron and packaged Peek may need separate Microphone and Screen Recording grants. Native modifier detection depends on an architecture-compatible addon and OS permissions. Shortcut conflicts can prevent registration. Producing arm64/x64 packages or running CI is not evidence of successful Intel and Apple Silicon hardware tests. Windows paths and native flags are implemented, but Windows is not claimed as end-to-end tested.

11. **Local does not mean offline / 本地应用不等于离线。** Audio clips go to the configured transcription API. Screenshots, recent transcripts, user intent and selected article passages go to the chat API. A typed key briefly exists in the isolated setup renderer before restricted IPC submission; it is cleared rather than filled back in. Saved keys are decrypted and used in the main process and are never returned to a renderer. Optional legacy `.env` files still contain plaintext if you choose to use them. The app does not intentionally save audio, screenshots, transcripts or conversations; settings, the selected library path, and encrypted credentials are persisted. This does not control OS swap, crash tooling, provider retention or your vault’s own backup/sync. Do not publish keys or personal articles with the source.

12. **Credential storage / 密钥保护有边界。** `credentials.enc` is encrypted with Electron `safeStorage`; macOS keeps its encryption key in Keychain, while Windows uses DPAPI. This is protection at rest, not protection against a compromised running app, operating system, or all software running as the same Windows user. System storage can be locked or unavailable. Unsigned macOS builds may prompt for Keychain access again after updates. Peek refuses plaintext fallback and does not silently overwrite unreadable saved credentials. If saved credentials cannot be read, unlock the system keychain and restart Peek first; the existing encrypted file is preserved. Keep the original key available in your own secure password manager for recovery. Removing a key in Peek disables its environment fallback but does not revoke the provider key or erase an existing `.env`. [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)

## Before a real presentation / 上台前

Choose the article beforehand, rehearse one Chinese and one English spoken question using Option+Space, open their source passages, check the audience display, and confirm the selected input actually hears the intended speaker. Check the result with your own real articles and hardware. Those manual checks remain the operator’s responsibility; repository tests cannot substitute for them.
